# Instruções - Miniprojeto Erenice Analise_T9

## Como rodar
Abra no VSCode ou Google Colab e rode todas as células, ou no terminal:

python limpeza.py

O arquivo limpo será gerado em: dados/Base Varejo_limpa.csv

## Arquivos do projeto
- limpeza.py (código principal)
- dados/Base Varejo.csv (base original)
- dados/Base Varejo_limpa.csv (base após limpeza)
- README.md
